# 🔥 習慣トラッカー (Habit Tracker)

毎日の習慣をワンタップで記録し、連続日数（ストリーク）とカレンダーで継続を可視化するシンプルなWebアプリです。

サーバー不要・インストール不要。ブラウザだけで動作し、データは端末の `localStorage` に保存されます。スマホ・PCどちらでも使えます。

## 使い方

`index.html` をブラウザで開くだけで動作します。

ローカルサーバーを使う場合:

```bash
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## 機能

- **習慣の追加・編集・削除** — 名前、アイコン（絵文字）、カラーを選択
- **ワンタップ記録** — 丸ボタンをタップして今日の達成を記録（再タップで取り消し）
- **ストリーク表示** — 現在の連続日数 🔥 と最長記録を自動計算
- **直近7日ストリップ** — 各習慣カードに直近1週間の達成状況を表示
- **月間カレンダー** — 習慣名をタップすると月ごとの達成カレンダーを表示（前後の月へ移動可能）
- **サマリー** — 今日の達成数 / 最長ストリーク / 累計達成回数
- **オフライン対応** — データはすべて `localStorage` に保存（外部通信なし）

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | 画面構造（習慣リスト・追加ダイアログ・カレンダーダイアログ） |
| `css/style.css` | スタイル（モバイルファースト） |
| `js/app.js` | アプリロジック（状態管理・ストリーク計算・描画） |

フレームワークやビルドツールは使用していません（Vanilla JS）。

## データ形式

`localStorage` のキー `habit-tracker:v1` に以下の形式で保存されます:

```json
[
  {
    "id": "uuid",
    "name": "朝のストレッチ",
    "emoji": "🏃",
    "color": "#6c5ce7",
    "createdAt": "2026-06-12",
    "doneDates": ["2026-06-11", "2026-06-12"]
  }
]
```
